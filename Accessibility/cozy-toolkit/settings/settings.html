Getting Started

Click the Cozy icon in your toolbar to open the popup. Use Enable Cozy to turn everything on or off.

Quick presets — not sure where to start? Pick one:

  • Dyslexia — readable font + reading ruler + warm tint
  • ADHD — paragraph focus + hide distractions + bionic reading
  • Sensory — freeze animations + calm overlay
  • Low Vision — large font + high contrast + big cursor

You can fine-tune any setting after applying a preset.

Read Features
  • Font & Typography — swap page fonts to OpenDyslexic, Lexend, or Atkinson Hyperlegible. Adjust size, spacing, and weight.
  • Bionic Reading — bolds the start of each word so your eyes glide faster. Light, Medium, or Strong.
  • Reading Ruler — a guide strip that follows your cursor. Set height, opacity, and color.
  • Writing Comfort — applies your font and spacing to text boxes and forms too.
  • Text-to-Speech — select any text on a page to hear it read aloud. Pick speed and voice.
Visual Features
  • Color Tint — colored overlay to soften harsh backgrounds. Adjust color, opacity, brightness, contrast, and temperature.
  • Color Filter — filters for protanopia, deuteranopia, or tritanopia.
  • Reading Mode — strips page clutter, shows just the article. Set max width and background.
  • Large Cursor — makes your cursor bigger and easier to spot.
Focus Features
  • Sensory Controls — freeze CSS animations, hide GIFs, reduce motion, pause autoplay videos.
  • Paragraph Focus — dims everything except what you're reading. Use j/k keys to move between paragraphs, or click to lock.
  • Hide Distractions — removes sidebars, ads, cookie banners, floating elements, comments, and social buttons.

Heads up: Some sites (like Reddit) may need you to disable Cozy on that site for focus features to work correctly. Use the "Disable here" button in the popup if things look off.

Keyboard Shortcuts
  • j / k — next / previous paragraph (when Paragraph Focus is on)
  • Click — lock focus on a paragraph
  • Select text — triggers Text-to-Speech (when TTS is on)
