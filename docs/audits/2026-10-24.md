# Published Chrome Web Store screenshot extensions — audit

**16 extensions checked, 24 pages checked, 47 browser assertions passed, 32 Node tests passed.** Product changes are limited to **four published extensions**. Published status is taken from the supplied screenshot; source versions differ from several store versions.

The exact scope is [scripts/published-scope.cjs](../../scripts/published-scope.cjs). Draft listings (Read Aloud, both Are You Cooked? entries and Pink Anti-Doomscroll), rejected Sponsor Skip, the missing Retro Pink theme source and every project absent from the screenshot are excluded. Browser and manifest tests are restricted to the allowlist.

## Fixes retained

- **Cookie Banner Blocker:** CSS now follows the enable/allowlist state. Disabling restores original inline display values; re-enabling and allowlisting work on the current page without requiring reload.
- **LoveSpark Notes:** recent saved popup drafts reopen after automatic title generation; explicit titles are restored and deleted notes are skipped. Fonts are bundled locally instead of fetched remotely.
- **Reddit Ad Blocker:** ad matching now includes the inserted node itself, fixing dynamically added ad posts while preserving ordinary posts.
- **Link Cleaner:** restore its archived source into the consolidated repository. Preserve application history state, resolve relative links against the document base URL, and re-clean links when their href changes. [Upstream provenance](../../privacy/lovespark-link-cleaner/UPSTREAM.md).

Each changed extension has a patch-version bump and an entry in its BUGS_AND_ITERATIONS.md. Existing extensions gained no API or host permissions; restored Link Cleaner retains its upstream permissions. Permission inventories are recorded in [results.json](2026-10-24/results.json).

## Reproduction and evidence

- [Test commands](../../tests/README.md); [machine-readable results](2026-10-24/results.json).
- Chromium: Chrome for Testing 153.0.8010.12, Playwright 1.62.1. Node 26.10.0.
- `npm test`: 16 existing scoped JavaScript tests plus 16 manifest/resource checks; all 32 passed.
- `AUDIT_RUN=published FUNCTIONAL=1 CONTENT=1 npm run test:browser`: all 16 extensions, 24 pages and 47 scenario assertions passed using disposable browser profiles.
- Raw results, full-page screenshots and logs are kept locally under ignored `work/published/` and `work/published.log`.
- Source scan of the selected first-party JavaScript/HTML found no remote script loading or dynamic eval/Function use. Bundled vendor libraries were excluded; this is not a complete security certification.

## Limits and release status

These results describe repository source, not the installed Chrome Web Store binaries. Fixtures do not verify every live consent manager, Reddit/YouTube layout or ad network. Long-running timer suspension and Firefox behavior were not tested. `ls-check`, the external LoveSpark scripts/docs and automation helper were unavailable; the Atlas URL could not be read. Those gates are not claimed as passed.

No Web Store submission or publication was performed. The PR's final source diff is restricted to the four published projects above; shared test tooling is restricted to the 16-project scope.
