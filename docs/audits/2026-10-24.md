# Extension audit — 2026-10-24

The repaired source passes real Chromium loading and page checks for **115 extensions / 130 pages**, with **148 passing interaction/content assertions**. **66 extensions** received fixes and a patch-version bump. The 20 distinct extension projects from the supplied store screenshot are included; the missing Retro Pink browser theme is excluded. The duplicate Are You Cooked? listing maps to one source project.

## Evidence and scope

- Base checkout: `68a3792` of the consolidated repository. Link Cleaner was absent and restored from its archived upstream at `37597b19568b789ba65a98e155d0f3151029fcc4`; see its [provenance](../../privacy/lovespark-link-cleaner/UPSTREAM.md).
- Baseline: 114 extensions, 45 failed browser checks. One was a harness assumption about Rewire Brain onboarding, corrected by completing onboarding through the UI; 44 had actual load, script, CSP or asset errors. Subsequent interaction tests found defects that a successful page load alone did not reveal.
- Final: 115/115 load checks, 130 pages without reported runtime/resource errors, 148/148 scenario assertions. The Core dashboard's label-only follow-up was rechecked separately and merged into the recorded final results.
- Unit/resource checks: **191 passed** (76 existing JavaScript tests plus 115 manifest checks); **2 Python checks passed**. Sponsor Skip package validation and its standalone real-Chrome ping test passed. Syntax checks passed for 96 changed/new JavaScript files before the final test-only smoke correction, which also passed its package syntax check.
- Browser: Chrome for Testing 153.0.8010.12, Playwright 1.62.1; Node 26.10.0. Each extension was installed/uninstalled in a disposable profile. No personal browser data was used.
- Reproduction: [tests/README.md](../../tests/README.md). Machine-readable coverage, permissions, baseline errors and repairs: [results.json](2026-10-24/results.json). Raw run output and all screenshots remain under ignored `work/verified/`; the targeted dashboard recheck is in `work/core-final/`.

## Repaired failure classes

1. **Sponsor Skip never initialized correctly.** `core.js` and its consumers declared the same lexical names in one global scope. Isolating the core fixes worker/content startup; callbacks make asynchronous message replies portable. The unit harness now loads the real scripts together. The legacy Chrome smoke test now sends its ping from a popup, since a worker cannot receive its own runtime message.
2. **Disabled cookie blocking still hid consent UI.** CSS now follows the enable/allowlist state. Disabling restores preexisting inline display values; re-enabling and allowlisting work on an already open page.
3. **Links and dynamic ads behaved incorrectly.** Link Cleaner preserves application history state, resolves document-relative URLs correctly and handles reused SPA links. Reddit's blocker now checks the inserted node itself. UTM Stripper retains ambiguous parameters that applications may use.
4. **Saved Notes drafts failed to reopen.** Automatically generated titles no longer disqualify a recent draft; explicit titles are restored and trashed notes are skipped.
5. **Shared UI failures.** Missing local font/icon/mascot assets were restored; remote font requests in Notes and Bridge became local. Footer load order and unsupported calls were fixed. 34 popups now insert their footer HTML. Theme handlers support both markup variants, persist choices and handle Escape; duplicate game listeners were removed.
6. **Other runtime and usability fixes.** Dopamine Control's inline script/styles moved to local files under its existing CSP. Twitch Adblock stopped accessing a nonexistent icon. CWS Filler retains its permissionless design. Are You Cooked? updates its count live. Read Aloud saves speed before relaying to a page. Core dashboard controls have accessible names.

## Permissions and security review

Existing extensions received **no new API or host permissions**. The recovered Link Cleaner retains its upstream permissions. Permission inventories are recorded in results.json. A source scan of the 20 screenshot projects found no remote `<script src>` loading or dynamic `eval`/`Function` use in the inspected first-party JavaScript/HTML; bundled vendor libraries were excluded from that scan. CSP fixes externalize local code instead of relaxing policy. This is a targeted engineering audit, not a full security certification.

## Limits and release status

- Source versions differ from several published store versions. These results describe this checkout, not the installed store binaries.
- Live YouTube/SponsorBlock availability, every real consent manager/ad layout, actual speech audio, long-running timer suspension and Firefox behavior were not validated. The Read Aloud popup test deliberately runs on a restricted extension URL and checks preferences, not audible reading.
- The store's Sponsor Skip rejection reason was not available; these repairs do not establish store acceptance.
- `ls-check`, Bun, the referenced external LoveSpark scripts/docs and automation-log helper were unavailable in this environment. The Atlas URL could not be read. None of these gates is claimed as passed.
- No Chrome Web Store submission, publication or production rollout was performed.
