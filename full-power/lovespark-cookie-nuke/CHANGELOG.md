# Changelog

All notable changes to LoveSpark Cookie Annihilator will be documented in this file.

## [1.0.8] - 2026-03-21

### Added
- Three-layer banner removal: CSS hiding, declarativeNetRequest blocking, MutationObserver detection
- Auto-reject: clicks "Reject All" / "Decline" / "Necessary Only" buttons
- Settings fallback: opens cookie settings, unchecks optional cookies, saves minimal consent
- Multi-language reject button support (EN, DE, FR, IT, ES, PT)
- Post-nuke cleanup: removes dark overlays, restores scroll-locked pages
- Daily and lifetime banner counter with badge display
- Hourly alarm for daily counter reset
- 50+ banner container selectors covering major consent platforms
- Generic fallback selectors for cookie/GDPR banner patterns
- Support for OneTrust, CookieBot, Didomi, Quantcast, Usercentrics, iubenda, Termly, Complianz, Osano, SourcePoint, TrustArc, CookieScript, CookieFirst, CookieYes, Axeptio, Borlabs, Moove GDPR, Evidon, Civic Cookie Control
- LoveSpark themed popup with 4 themes (Retro Pink, Dark, Beige, Slate)
- Enable/disable toggle
- Chrome Web Store listing
