# LoveSpark Core

The LoveSpark Suite hub extension. Provides a shared dashboard for managing LoveSpark modules (cursor packs, anti-doomscroll, focus tools) from a single place.

## Features

- **Cursor Pack** — 10 hand-crafted cursor themes (Retro Pink, Sakura Peach, Starlight Purple, Moonlight Rose, Candy Floss, Cyber Cherry, Mint Blossom, Golden Hour, Holographic, Obsidian Heart)
- **Site Exclusions** — disable LoveSpark on specific domains
- **Data Export / Import** — portable settings JSON
- **Privacy-first** — all state stored locally via `browser.storage.local`, no telemetry

## Privacy

No data collection. No remote code. No ads. Local storage only. MIT licensed.

## Install

Available for Chrome, Firefox, and Edge. Search "LoveSpark" in your browser's extension store, or load unpacked from this directory.

## Development

Vanilla JavaScript, Manifest V3, no build step. Edit and reload.
