# LoveSpark Dashboard

One-stop control panel for every browser extension you have installed. Retro pink
aesthetic, filterable by category, searchable, with one-click enable/disable.

## Features

- Enable, disable, and count all installed extensions from a single page
- LoveSpark suite members surface first with a pink highlight
- Category tabs (Ad Blockers, Privacy, Productivity, Dev Tools, Media, Shopping, Other)
- Live search across names and descriptions
- Dark retro theme with scanline overlay
- Reacts to install / uninstall / enable / disable events in real time

## Install

Load unpacked from `chrome://extensions` (Developer Mode on) or install from the
Chrome Web Store.

## Permissions

- `management` — read installed extensions and toggle their enabled state
- `tabs` — find an already-open Dashboard tab by URL and focus it instead of
  opening a duplicate

No user data is collected, transmitted, or stored.
