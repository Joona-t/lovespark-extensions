# Focus Blossom

Grow a pixel garden by blocking distracting sites. Part of the LoveSpark Suite.

- Free, open-source, MIT licensed
- No ads, no tracking, local storage only
- 4 themes: Retro Pink, Dark, Beige, Slate

## Install
Load unpacked from Chrome `chrome://extensions`, or install via Chrome Web Store.

## Privacy
All garden data stays in `chrome.storage.local` — never leaves your device.
