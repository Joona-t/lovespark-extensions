# LoveSpark Calm

One toggle makes any page sensory-friendly — mute harsh colors, stop animations, hide distractions. Calm, low-stimulation browsing for neurodivergent users.

Part of the LoveSpark suite. Free, open-source, no ads, no data collection, no accounts. Local storage only.

## What it does

- Mutes saturated colors on the current page
- Stops CSS animations and autoplay motion
- Hides common distraction elements (ads, popups, notification badges)
- Per-site toggle so calm mode only applies where you want it

## Permissions

- `storage` — remembers your per-site calm-mode preference locally
- `activeTab` / `scripting` — applies the calm-mode stylesheet to the page you're viewing

See `PRIVACY.md` for the full data-handling breakdown.

## Install

Load unpacked from `chrome://extensions` (Developer mode) or install from the Chrome Web Store / Firefox Add-ons once published.
