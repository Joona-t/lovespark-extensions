# LoveSpark Context Switch

Log every task switch and see your daily context-switching count. An ADHD-friendly focus tracker for task-switching awareness.

Part of the [LoveSpark Suite](https://github.com/Joona-t) — retro pink productivity tools for a calmer internet.

## Features

- One-tap logging of each task switch from the toolbar popup
- Live daily context-switch count so you can see your task-switching patterns
- Automatic daily reset for a clean baseline each day
- OpenDyslexic-friendly typography, retro-pink theme, full keyboard navigation, reduced-motion support
- Zero data collection — everything stays on your device

## Privacy

Your context-switch count **never leaves your device**. No accounts, no cloud, no analytics, no tracking. All data is stored locally in `chrome.storage.local`. See [PRIVACY.md](PRIVACY.md) for the full policy.
