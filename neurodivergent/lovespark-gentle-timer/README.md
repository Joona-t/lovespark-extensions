# LoveSpark Gentle Timer

Gentle time awareness for ADHD brains. See how long you've been on a site — no shame, just awareness.

Part of the [LoveSpark Suite](https://github.com/Joona-t) — retro pink productivity tools for a calmer internet.

## Features

- Tracks time spent per site today, shown in the popup
- Gentle break reminders (water, food, movement) on a configurable interval
- Optional floating on-page badge showing elapsed time, dims to stay unobtrusive
- Per-domain allowlist to exclude sites from tracking
- 4 themes: Retro Pink, Dark, Beige, Slate

## Privacy

Your time-tracking data **never leaves your device**. No accounts, no cloud, no analytics, no tracking. All data is stored locally in `chrome.storage.local`. The extension's content script only measures time-on-page per domain — it never reads page content.
