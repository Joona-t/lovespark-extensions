# LoveSpark Gentle Timer

Gentle time awareness for ADHD brains. See how long you've been on a site — no shame, just awareness.

Part of the LoveSpark suite. Free, open-source, privacy-first (local storage only, no accounts, no data collection).

## Features

- Tracks time spent per site today, shown in the popup
- Gentle break reminders (water, food, movement) on a configurable interval
- Optional floating on-page badge showing elapsed time
- Per-domain allowlist to exclude sites from tracking
- 4 themes: Retro Pink, Dark, Beige, Slate
