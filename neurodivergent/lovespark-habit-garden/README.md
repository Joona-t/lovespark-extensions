# LoveSpark Habit Garden

A gamified habit tracker that grows a garden as your streaks bloom. Built for ADHD brains — no account, no tracking, always free.

Part of the [LoveSpark Suite](https://github.com/Joona-t) — retro pink productivity tools for a calmer internet.

## Features

- Add daily habits, one plant per habit
- Mark a habit done and watch its plant grow a stage closer to full bloom
- Streak tracking — see consecutive days kept per habit
- Whole-garden view so progress is something you look at, not remember
- Gentle automatic daily reset so streaks stay honest
- OpenDyslexic-friendly typography, retro-pink theme, full keyboard navigation, reduced-motion support
- Zero data collection — everything stays on your device

## Privacy

Your habits and streaks **never leave your device**. No accounts, no cloud, no analytics, no tracking. All data is stored locally in `chrome.storage.local`. See [PRIVACY.md](PRIVACY.md) for the full policy.
