## 2026-03-28: Fleet-wide automation regression — broken CSS variables + missing footers

**Problem:** A post-swarm-audit automation run injected `lovespark-tokens.css` and `lovespark-base.css` into popup.html, and replaced `--ls-pink-accent` with undefined `--ls-btn-bg` in popup.css. This broke toggle colors (rendered transparent) and changed disabled opacity from 0.4 to 0.9. Footer buttons were also missing from 26 extensions.
**Root cause:** Batch automation (`sync-shared-lib.sh` or swarm pass) overwrote extension CSS without validating variable definitions. The `--ls-btn-bg` variable was never defined in any CSS file.
**Fix:** Reverted all 76 git repos to last committed state. Fixed 3 extensions (cookie-nuke, breathe, planner) that had the bug baked into commits. Added footer buttons (LoveSpark Suite, Ko-fi, Report a Bug) to all 26 missing extensions. Updated shared lib footer to make LoveSpark Suite a proper link to lovespark.love. Deployed `guard-fleet-sync.sh` — 4-gate pre-sync validator that blocks automations introducing undefined CSS variables.
**Files:** popup.css, popup.html, lib/lovespark-footer.js, lib/lovespark-footer.css
**Commit:** fleet-wide fix, multiple commits

## 2026-07-08: ITER-CWS-A11Y-1 — 4 real a11y/brand fails blocking pre-commit hook + CWS bundle commit

**Problem:** `ls-check .` failed with 4 real errors that blocked the pre-commit hook from letting the already-staged CWS submission bundle (CWS-LISTING.md, PRIVACY.md, SUBMIT.md, cws-shots/, the synced shared-lib files) land: (1) A11Y-DIALOG — popup.html's `.popup-container` had no `role="dialog"`/`aria-labelledby`; (2) A11Y-EXPANDED — the theme dropdown trigger had no `aria-expanded`; (3) A11Y-LABEL — 5 emoji-only buttons across settings.html/onboarding.html had no `aria-label`; (4) BRAND-LIB-WIRED — popup.html never loaded `lib/lovespark-base.css` or `lib/lovespark-theme.js`, even though both files exist in `lib/` (this repo forked its own local theme-dropdown implementation in popup.js instead of using the shared lib). Also fixed A11Y-KI004 (`.med-card.taken` opacity 0.8 fails beige contrast) and SEC-SENDMSG (3 fire-and-forget `UPDATE_BADGE` sendMessage calls with no error handling).
**Root cause:** popup.html/popup.js predate the fleet's shared-lib theme-dropdown convergence and were never migrated; the a11y dialog/expanded/label attributes were never added when the popup was built.
**Fix:** Added `role="dialog" aria-labelledby="popupTitle" aria-describedby="popupDesc"` to `.popup-container`; added static `aria-expanded="false" aria-haspopup="true"` to the theme trigger in popup.html and settings.html; added `aria-label` to the 5 emoji buttons (Export/Import/Doctor Report/Clear All Data/Open Med Tracker). Wired `lib/lovespark-base.css` + `lib/lovespark-theme.js` into popup.html and removed the duplicate local `applyTheme`/dropdown-toggle logic from popup.js in favor of `LoveSparkTheme.apply()` — kept the legacy `darkMode`-boolean fallback (custom init, not `LoveSparkTheme.init()`, since the shared init doesn't know about that legacy key) and added live `aria-expanded` toggling on open/close as a bonus correctness fix. Factored the 3 `UPDATE_BADGE` sendMessage call sites into one `updateBadge()` helper wrapped in try/catch. Raised `.med-card.taken` opacity to 0.85. `ls-check .` went from 28 pass/4 fail/4 warn to 33 pass/0 fail/3 warn; `--strict` from 8 fail to 2 (A11Y-LIVE + MV3-STORAGE-KEY, both checker false positives — see repo-wide note in lovespark-hub's BUGS log, same root cause: shorthand `{ theme }` storage.set). Verified `node --check` on both edited JS files. Committed the CWS bundle together with these fixes now that the pre-commit hook passes.
**Files:** popup.html, popup.js, settings.html, onboarding.html, popup.css, manifest.json (1.0.36 → 1.0.37)
