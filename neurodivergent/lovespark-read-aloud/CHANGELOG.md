# Changelog

## [1.0.0] - 2026-03-25

### Added
- Text-to-speech for any webpage using Web Speech API
- Sentence-by-sentence highlighting with auto-scroll
- ADHD speed presets: Chill (0.8x), Flow (1.0x), Turbo (1.5x), Hyperfocus (2.0x)
- Reading position memory per page (resume where you left off)
- Voice selector with all system voices
- Transport controls: play/pause, previous, next, stop
- Progress bar with sentence counter
- Daily and total reading statistics
- Keyboard shortcut: Alt+Shift+R to toggle reading
- 4 themes: Retro Pink, Dark Noir, Warm Beige, Cool Slate
- Full WCAG 2.1 AA accessibility (contrast, keyboard nav, ARIA, reduced motion)
- Privacy-first: all processing local, no data collection
