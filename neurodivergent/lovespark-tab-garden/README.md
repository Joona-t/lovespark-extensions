# LoveSpark Tab Garden

Gamified tab manager for neurodivergent coders. Idle tabs become plants in your garden — restore them anytime by "watering" them.

Part of the [LoveSpark](https://github.com/Joona-t) suite: free, open-source, privacy-first browser extensions.

## Features

- Auto-archive idle tabs after a configurable threshold (15 min – 2 hr)
- Visual garden grid of archived tabs as plants
- Search archived tabs
- Configurable max garden size and excluded domains
- 4 themes: Retro Pink, Dark, Beige, Slate
- Local-only storage — no tracking, no network calls

## Privacy

All data stays in `chrome.storage.local` on your device. No analytics, no remote code, no data collection.
